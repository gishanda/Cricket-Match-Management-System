# 🏏 Cricket Match Management System

## 📌 Overview

The **Cricket Match Management System** is a software application designed to manage and organize cricket matches efficiently. It helps in handling match scheduling, team management, player statistics, scoring, and result tracking in a streamlined way.

This system can be used by tournament organizers, clubs, or cricket enthusiasts to digitize and simplify match operations.

---

## 🚀 Features

* 🧑‍🤝‍🧑 **Team Management**

  * Create, update, and delete teams
  * Manage player details for each team

* 📅 **Match Scheduling**

  * Schedule matches with date, time, and venue
  * Assign teams to matches

* 🏏 **Live Scoring**

  * Ball-by-ball score updates
  * Track runs, wickets, overs, and extras

* 📊 **Statistics Tracking**

  * Player performance (runs, wickets, strike rate, etc.)
  * Team statistics and match history

* 🏆 **Match Results**

  * Automatic result calculation
  * Display winner and match summary

* 📂 **Data Management**

  * Store match and player data
  * Easy retrieval and updates

## ⚙️ Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/gishanda/Cricket-Match-Management-System.git
   cd cricket-match-management-system
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

   *(or relevant package manager)*

3. **Run the application**

   ```bash
   npm start
   ```

4. Open your browser and go to:

   ```
   http://localhost:3000
   ```

## 📖 Usage

1. Create teams and add players
2. Schedule a match between teams
3. Start the match and update scores in real time
